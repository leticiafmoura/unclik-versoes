# Unclik — Versões da home

Publicação das versões 3, 6 e Alterações da home da Unclik, com conteúdo e design preservados.

Site estático em HTML, CSS e JavaScript. Cada pasta contém seus próprios arquivos e imagens. A publicação pelo GitHub Pages usa a branch `main`, pasta raiz; `.nojekyll` mantém a entrega direta dos arquivos. Atualizações nesta branch são publicadas automaticamente.

Links e formulários preservam o comportamento demonstrativo das versões de origem.
