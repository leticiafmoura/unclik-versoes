Site estático em HTML, CSS e JavaScript. As páginas Planos e Quem somos compartilham arquivos de `alteracoes/`; essas três pastas devem ser publicadas juntas. A publicação pelo GitHub Pages usa a branch `main`, pasta raiz; `.nojekyll` mantém a entrega direta dos arquivos. Atualizações nesta branch são publicadas automaticamente.

Links e formulários preservam o comportamento demonstrativo das versões de origem.
